SD-Karten-Images · Vorabversion

Raspberry Pi

64 Bit · Zero 2 W und Pi 3/4/5

Image für Ihr Modell herunterladen und mit Raspberry Pi Imager auf eine SD-Karte ab 8 GB schreiben. Danach die Konfigurationsdatei auf die Boot-Partition kopieren und bei WLAN-Nutzung die Zugangsdaten eintragen. Der Player startet automatisch im Vollbild; die Kopplung bleibt nach Neustarts erhalten. Neue Images aktualisieren ihre Player-Komponenten bei HTTPS-Verbindung automatisch.

Downloads über GitHub: Für dieses private Repository ist eine Anmeldung mit Zugriffsberechtigung erforderlich. Die Images wurden gebaut und geprüft; Tests mit HDMI, WLAN und Videos auf echten Geräten stehen noch aus. Der ursprüngliche Pi Zero und Zero W werden nicht unterstützt.

Anleitung und SHA-256-Prüfsummen ↗

Zwei Möglichkeiten

Universal oder bereits zugeordnet.

01

Universal Player

Der Download auf dieser Seite zeigt beim ersten Start einen Code. Damit ordnen Sie den Player anschließend im Backend einem Display zu.

02

Display-Player

Im Backend können Sie am gewünschten Display einen bereits fertig zugeordneten Windows-, Linux- oder macOS-Player herunterladen. Dieser startet ohne Kopplungscode.

Zum Backend ↗

In drei Schritten

Einmal koppeln.
Danach automatisch starten.

  1. 01
    Player auswählen

    Browser-Player direkt starten oder das passende Windows-, Linux- beziehungsweise macOS-Paket herunterladen.

  2. 02
    Code am Bildschirm ablesen

    Beim ersten Start erscheint ein sechsstelliger, zeitlich begrenzter Kopplungscode.

  3. 03
    Im Backend zuordnen

    Unter Displays beim gewünschten Display „Player einrichten“ öffnen und den Code über „Code koppeln“ eingeben.
